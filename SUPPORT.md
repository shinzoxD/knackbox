# Support

Knackbox is maintained by volunteers. Use the channel that matches your request
so it reaches the right people.

## Installation and usage help

Read the [website documentation](https://knackbox.pages.dev/docs/) first. For
questions, compatibility reports, and help using a skill, open a
[GitHub Discussion](https://github.com/shinzoxD/knackbox/discussions).

Include:

- Skill name and Knackbox commit or content digest.
- Agent and version, such as Claude Code, Codex, OpenCode, or Cursor.
- Installation command and relevant non-sensitive output.
- Expected behavior and what happened instead.

## Bugs and feature requests

Use [GitHub Issues](https://github.com/shinzoxD/knackbox/issues) for reproducible
bugs and scoped feature requests. Use the provided forms and search existing
issues before opening a new one.

To request a new skill or claim a good first contribution, see
[COMMUNITY.md](COMMUNITY.md) and open a
[skill request](https://github.com/shinzoxD/knackbox/issues/new?template=skill_request.yml).

## Security reports

Do not disclose vulnerabilities in an issue or discussion. Follow
[`SECURITY.md`](SECURITY.md) and use the repository's private vulnerability
reporting flow.

## Scope

This project can support Knackbox skills, installers, catalog data, and the
website. Problems in an agent runtime or third-party API should be reported to
that project's support channel after confirming the problem is not specific to
a Knackbox skill.

There is no guaranteed response time or private consulting support. Clear,
reproducible reports are prioritized.
