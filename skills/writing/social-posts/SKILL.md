# Social Posts

Social rewards specificity and voice. Lead with the point; earn the scroll.
No engagement-bait lies.

## Workflow

1. Platform (LinkedIn / X / Instagram caption / multi), goal, audience, CTA.
2. Hook in the first line (no throat-clearing).
3. One idea per post; threads = sequenced ideas.
4. Draft 2–3 variants (direct, story, contrarian) when useful.
5. Hashtags sparingly; emoji only if brand-fit.
6. Compliance: disclosures for affiliates/employers when relevant.

## Formats

### Single post
Hook → 2–5 short lines → CTA

### Thread
1/ hook + promise
2..n/ one point each
Final / CTA + summary

## Rules

1. Do not invent stats, customers, or screenshots descriptions as facts.
2. Prefer concrete verbs and numbers the user provided.
3. Cut jargon unless audience is expert.
4. Respect platform norms: LinkedIn can be longer; X tighter.
5. Avoid manufactured outrage and fake "comment yes if".
6. Offer alt text suggestions when an image is part of the post.

## Edge cases

- **Employer brand voice:** match samples if given.
- **Sensitive topics:** calmer tone, no overclaim.
- **Thread too long:** compress; offer a single-post alternative.
