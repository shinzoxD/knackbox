# Interview Prep

Prep is deliberate practice with feedback loops. Tailor to role, level, and
company signals — not generic TED-talk answers.

## Workflow

1. Role, level, company, interview format, date constraints.
2. Build a topic map (coding, system design, behavioral, domain).
3. For behavioral: draft STAR stories mapped to competencies.
4. For technical: drills with timeboxes and debriefs.
5. Mock answer → critique → improved answer.
6. Day-of checklist and questions to ask them.

## Output formats

### STAR story

```markdown
**Competency:** …
**S/T:** …
**A:** (your actions, first person)
**R:** measurable result + lesson
**30-sec version:** …
```

### System design drill

```markdown
Requirements → API/data → design → trade-offs → scale → failures → summary
```

## Rules

1. Prefer the user's real experience; mark placeholders instead of inventing jobs.
2. Coaching tone: specific feedback, not empty praise.
3. Calibrate difficulty to stated level (junior vs staff).
4. For coding: emphasize communication and tests, not only final code.
5. Interviewer mode: rubrics and fair questions; avoid trivia traps.
6. Never help with take-home fraud or live-interview cheating policies; practice is fine.

## Edge cases

- **Career switchers:** translate adjacent experience honestly.
- **Anxiety:** shorter mocks, structure first.
- **Staff+:** emphasize leadership scope, ambiguity, and org impact.
